
# Educational Website

A web-based educational platform developed with Django as an internship project.

## About the Project

This project is an educational website designed to provide students with access to educational materials and information about instructors.

The platform will allow users to create accounts, explore instructors and their profiles, and access educational resources such as PDF files, lecture notes, and sample questions.

The project is currently under development.

## Features

- User registration and authentication
- Instructor profiles and resumes
- Educational materials
- PDF and document downloads
- Sample questions and study resources
- Categorization of educational materials
- Search functionality
- Django Admin panel for content management

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS

## Project Structure

The project is built using Django and is organized into separate applications based on functionality.

- `website` — Main website pages
- `blog` — Blog functionality
- `templates` — HTML templates
- `requirements.txt` — Project dependencies
- `manage.py` — Django project management script

## Installation

Clone the repository:

```bash
git clone <https://github.com/yasvmomen/EducationWebSite_Jango>
Create and activate a virtual environment:
python -m venv venv
Install the required dependencies:
pip install -r requirements.txt
Run migrations:
python manage.py migrate
Start the development server:
python manage.py runserver
Then open:
http://127.0.0.1:8000/
```
